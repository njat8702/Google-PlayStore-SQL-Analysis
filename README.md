# 📊 Google Play Store Apps Data Analytics (SQL)

## 📌 Project Overview
This project focuses on analyzing the Google Play Store apps dataset using **SQL** to uncover business insights regarding app ratings, installation metrics, revenue generation, and user sentiments.

## 🛠️ Tech Stack & Skills
*   **Database Engine:** MySQL / PostgreSQL
*   **SQL Concepts:** INNER JOINs, GROUP BY, HAVING, Aggregate Functions, Table Aliases, Logical Filters (`WHERE`, `ORDER BY`, `LIMIT`).

### 2. Business Insights Formulated

#### Q1: Identify top-performing applications based on customer ratings.
```sql
-- MS SQL Server Syntax
SELECT TOP 5 * FROM playstore_apps ORDER BY rating DESC;
```

#### Q2: Track total applications deployed across different store categories.
```sql
SELECT category, COUNT(app_name) AS totalApps 
FROM playstore_apps 
GROUP BY category;
```

#### Q3: Calculate the Total Revenue generated by each paid application.
```sql
SELECT app_name, category, (installs * price) AS Total_revenue 
FROM playstore_apps 
WHERE type = 'Paid'
ORDER BY Total_revenue DESC;
```

#### Q4: Filter categories that maintain high-quality standards (Average Rating > 4.5).
```sql
SELECT category, AVG(rating) AS avgRating 
FROM playstore_apps 
GROUP BY category 
HAVING AVG(rating) > 4.5;
```

#### Q5: Cross-reference apps with negative customer review sentiments for software debugging.
```sql
SELECT p.app_name, p.category, a.review_text 
FROM playstore_apps p 
INNER JOIN app_reviews a ON p.app_name = a.app_name 
WHERE a.sentiment = 'Negative';
```

## 📈 Key Business Takeaways
1. **Revenue Drivers:** Paid games and customization apps like *Minecraft* and *Nova Launcher* generate the highest monetization metrics.
2. **Quality Control:** Grouped category insights quickly highlight sectors falling below the 4.5-star user benchmark.
3. **Sentiment Mapping:** Merging transaction tables with sentiment files allows developers to pinpoint exactly which high-install apps require urgent stability updates.
